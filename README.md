Library updated and addresses most of the issues in the original commit. Not tested in the classroom, so please use at your own risk. If you make improvements, I would appreciate these being shared :)

### original commit description ###
This is my amateur attempt at adapting the Maqueen Micropython libraries available from TigerJython to the updated Maqueen Lite V5. As a user of the Maqueen PlusV2, I have been testing this new iteration as a lower cost entry into robotics for middle-school students and it brings with it a significant benefit (at least in my experience) - user replacable motors, a lack of which is a weakness for the PlusV2. Limited testing has shown that core features appear functional; however, this has not been tested directly in a classroom environment.
